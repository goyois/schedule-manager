일정이 어디까지 자동으로 처리될지 정합니다.

시작/종료 시각에 맞춰 상태 자동 변경
켜면 일정 시작 시각에 대기→진행중, 종료 시각에 진행중→완료로 서버가 자동으로 상태를 바꿉니다. 종료 시각이 없는 알림형 일정은 시작 시각에 바로 완료 처리됩니다. 끄면 시각이 지나도 상태는 직접 바꿔야 합니다.
AI 추천 일정 자동 등록 허용
켜면 AI 일정 추천 결과에 제목/시작 시각/카테고리가 모두 갖춰졌을 때 "자동 등록" 버튼이 나타나, 한 번의 클릭으로 검토 없이 바로 일정이 저장됩니다. 꺼두면 항상 "수동 등록"으로 폼을 확인/수정한 뒤 저장합니다.

반복 일정

등록해둔 반복 일정 목록입니다. 중단하면 앞으로 만들어질 일정 생성이 멈추고, 아직 지나지 않은 일정만 정리됩니다 - 이미 지난/진행 중인 일정은 기록으로 그대로 남습니다.
